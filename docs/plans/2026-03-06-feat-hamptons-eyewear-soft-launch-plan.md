# Hamptons New York: Manufacturing Plan

## Overview

Get 150 units of "The Classics" ($450 flat-top wayfarer) manufactured and in hand. Mazzucchelli Italian acetate, .925 sterling silver H-shaped hinge (rhodium coated), Carl Zeiss polarized glass lenses, OBE 5-barrel spring hinges. Genuine leather case, magnetic-close box with gold foil. Designed and assembled in New York City.

**Partners:** Sean DeFaria (51%) / Lukas Levine (49%)
**First run:** 150 units (50 seeded, 75 for sale, 25 reserve)
**Budget:** $20-35K total

1. File HH logo mark FIRST (strongest, no geographic issue)

3. Budget $2,500-$5,000 for initial IP (searches + 2 applications + attorney response)

**Sterling Silver H-Hinge -- key vendor: Vijay's NYC (47th Street)**
- Casting + finishing + rhodium plating under one roof
- $15-40/piece all-in (depending on complexity and volume)
- 2-4 week turnaround for first samples, faster for production
- Works from CAD files (STEP or STL format)
- Rhodium coating adds $3-5/piece, eliminates tarnishing permanently
- Process: lost-wax casting (wax carve, cast in silver, polish, rhodium plate)

**Mazzucchelli Acetate Sourcing**
- Acetate Italia sells individual sheets, no MOQ. Perfect for prototyping.
- Single sheet yields 8-12 frames depending on size
- Always request Mazzucchelli color codes to verify authenticity (stamped ID codes on genuine sheets)
- Do Eyewear (50 MOQ) and Heappy (60 MOQ) both confirmed to work with genuine Mazzucchelli

**Fastest path to 150 units:**
1. Order Mazzucchelli acetate from Acetate Italia (or have factory source with color code verification)
2. Send CAD files to Do Eyewear or Heappy for frame cutting/finishing with custom H-hinge cutouts
3. Sterling silver H-hinges cast by Vijay's NYC
4. Zeiss lenses from B2B program
5. Final assembly in NYC: mount hinges, set lenses, QC
6. Package in-house

**Top pick: Selin Olmsted Studio (Brooklyn)**
- Specialized in eyewear industrial design
- Brooklyn-based, can do in-person fittings
- Full service: concept sketches, CAD, prototyping, factory liaison
- $3,000-5,000 but eliminates coordination headaches

**Budget option: Upwork freelancer ($1,500-3,000)**
- Search "eyewear CAD designer" or "sunglasses product designer"
- Verify eyewear experience specifically (frame tolerances are unique)

**CAD tool:** Rhino 3D (industry standard). Deliverables must include:
- STEP files (universal, for manufacturing)
- Native Rhino files (for future modifications)
- 2D technical drawings with dimensions
- Rendered images for marketing

**Critical:** Get STEP files AND native files in the contract. Some designers only deliver STL (mesh only, hard to modify). STEP files are what factories need.
